# 실습 과제 1 — 처음 보는 환경에서도 잘 걷는 Ant 만들기

**주제: 평지 보행 정책의 도메인 랜덤화 파인튜닝과 보상 설계 비교**  
작성일: 2026년 10월 5일

> 이 보고서는 실제 체크포인트, TensorBoard 로그, 영상과 재평가 결과를 바탕으로 작성했다. 블록에서는 파인튜닝 모델의 평균 보상이 소폭 높았지만, 미학습 물결에서는 평지 기준 모델을 넘지 못했다. 초기 지면 접촉 충격과 학습·평가 배치 차이가 남아 있어, 결과를 일반적인 강건성 향상으로 확대 해석하지 않는다.

## 1. 연구개요

### 1.1 연구 목적

평지에서 보행을 학습한 Ant가 **학습하지 않은 환경에서도 전진과 자세 유지를 수행할 수 있는지** 확인한다. 지형의 높낮이와 마찰이 바뀌면 발의 접촉 위치와 미끄러짐, 몸통 자세가 달라져 기존 보행 정책의 성능이 저하될 수 있다.

이미 평지에서 학습한 하나의 정책을 공통 출발점으로 사용하고, 잔요철·사각 블록·경사와 마찰 랜덤화를 적용한 환경에서 추가 학습한다. 다음 두 실험을 비교한다.

- **실험 A:** 원본 보상함수를 유지한 도메인 랜덤화 파인튜닝.
- **실험 B:** 원본 보상에 안정성·정면 이동 관련 벌점을 추가한 도메인 랜덤화 파인튜닝.

로봇의 링크 길이, 관절 개수, USD 하드웨어 구조는 바꾸지 않았다. 목표는 높은 보상뿐 아니라 **환경 변화에 대한 적응, 보행 양상, 일반화의 한계**를 함께 분석하는 것이다.

### 1.2 평가 환경의 구분

| 평가 환경 | 학습과의 관계 | 확인하려는 내용 |
|---|---|---|
| 사각 블록의 새로운 배치 | 블록 종류·크기 분포는 학습에 포함, 배치와 평가 seed는 다름 | 학습한 지형 종류 안에서의 일반화 |
| 물결 지형 | 학습에 포함되지 않은 지형 종류 | 새로운 지형 종류로의 일반화 |

블록만 평가해서는 ‘처음 보는 지형 종류에서도 잘 걷는다’는 결론을 내리기 어렵다. 과제의 미학습 환경 평가에는 물결 지형을 사용하고, 블록은 보조 비교로 사용한다. **평가에 사용한 물결 지형으로 추가 학습하지 않았다.**

## 2. 연구가설

| 가설 | 근거 | 검증 방법 |
|---|---|---|
| H1. 여러 지형·마찰 조건에서 추가 학습하면 평지 기준 정책보다 환경 변화에 강건해질 것이다. | 다양한 접촉 조건에 노출되면 특정 평지 조건에 대한 의존이 줄어들 것으로 예상한다. | 평지 기준 모델과 실험 A를 같은 블록·물결 평가 환경에서 비교한다. |
| H2. 안정성·정면 이동 벌점을 추가하면 실험 A보다 수직 움직임과 비대칭 추진을 줄이고 안정적인 진행에 도움이 될 것이다. | 목표까지 이동하는 보상만으로는 원하는 보행 모양을 충분히 지정하기 어렵다. | 같은 초기 모델·학습량·지형·seed를 사용하는 A/B를 비교한다. 원본 보상, 에피소드 길이, 수직 속도와 영상을 함께 본다. |

A/B의 차이는 **추가 보상 네 항목의 묶음**이다. 이번 실험만으로 개별 항목의 효과를 분리할 수는 없다. 또한 평지 기준 모델보다 파인튜닝 모델의 총 학습량이 많으므로, H1을 엄밀히 검증하려면 ‘평지에서만 1,000회 더 학습한 모델’도 대조군에 추가해야 한다.

### 3.2 공통 학습 설계

평지 기준 체크포인트:

```text
logs/rsl_rl/ant/2026-09-17_13-21-32_ant_baseline/model_999.pt
```

평지 기준 모델은 1,000회 학습했다. A/B는 이 모델에서 **각각 독립적으로 1,000회 추가 학습**했다. A의 결과에서 B를 이어 학습한 것이 아니다. 기존 두 단계 파인튜닝 실험과도 구분하며, 본 보고서의 주 실험은 한 단계 파인튜닝이다.

| 설정 | A/B 공통 값 |
|---|---|
| 학습 환경 수 / seed | 4,096 / 42 |
| 추가 PPO 업데이트 | 각 1,000회 |
| 한 업데이트의 수집량 | 환경당 32스텝, 총 131,072 transition |
| 추가 학습 수집량 | 분기당 131,072,000 transition |
| 관측 / 행동 | 60차원 / 8차원 관절 effort 명령 |
| 정책·가치망 | 각각 은닉층 400–200–100, ELU |
| PPO | learning rate 0.0005, adaptive schedule, 5 epochs, 4 minibatches |
| 할인율 / GAE λ / PPO clip | 0.99 / 0.95 / 0.2 |
| 시뮬레이션 / 제어 주기 | 1/120초 / 1/60초 |
| 최대 에피소드 길이 | 16초 = 960 제어 스텝 |
| 외란 | 두 주 실험 모두 없음 |
| 재개 방식 | policy·critic·optimizer를 불러오는 `--resume` |

`--max_iterations 1000`은 재개 후의 추가 업데이트 수이다. 이 RSL-RL 실행에서는 저장된 iteration 999부터 번호를 이어 사용하여, 1,000회 파인튜닝의 마지막 파일이 `model_1998.pt`로 저장됐다.

#### 도메인 랜덤화 조건

| 요소 | 실제 학습 설정 |
|---|---|
| 잔요철 | 생성 확률 40%, 높이 −0.025~+0.025 m, 높이 간격 0.005 m, 공간 샘플링 0.4 m |
| 사각 블록 | 생성 확률 30%, 높이 −0.02 / −0.01 / +0.01 / +0.02 m, 구역당 300회 배치 |
| 블록 가로·세로 | 설정 범위 0.4~1.6 m, 생성기 격자 양자화로 실제 각 변은 0.4 또는 1.2 m |
| 경사 / 역경사 | 각각 15%, slope 파라미터 0.02~0.10; 각도 단위가 아님 |
| 평지 | 별도의 평지 타일은 제외. 블록 사이의 바닥과 중앙 플랫폼은 존재 |
| 지형 구성 | 학습 당시 20×20 m 타일 8×8, 가로·세로 총 160 m |
| 마찰 | 로봇 재질의 정지 마찰 0.5~1.25, 동적 마찰 0.4~1.0; 동적≤정지 |
| 마찰 배정 | 64개 후보 중 Ant마다 하나, 모든 충돌 형상에 적용; 생성 시 정하고 리셋 간 유지 |

비율은 타일 **생성 확률**이며, 매 에피소드에서 실제 경험한 지형 비율을 정확히 보장하지 않는다. 지형 전체를 매 에피소드 다시 생성하지 않는다. 학습 당시에는 구역 중심을 무작위로 다시 선택했다.

#### 학습 당시와 현재 평가 코드의 차이

두 최종 모델을 학습한 뒤 불필요한 기본 설정 변경을 정리했다. 따라서 현재 명령어가 가리키는 환경은 과거 학습 당시와 완전히 같지는 않다.

| 항목 | 실제 A/B 학습 당시 | 본 보고서 재평가 |
|---|---|---|
| 시작 XY | 18개 타일 중심 중 중복 허용 무작위 선택 | 원본의 5 m 간격 10×10 격자 |
| 지면 마찰 결합 | multiply | 원본의 average |
| 복제 옵션 | `clone_in_fabric=False` | 원본의 `True` |
| 지면 높이 조회 | 추가 ray 센서 | 지형 메시 직접 조회, 추가 센서 없음 |
| 지면 ray 실패 | 즉시 종료 | 원본 월드 높이 기준으로 판정 |
| 시작 높이 | 타일 중심의 보수적인 높이 + 0.5 m | 해당 XY 지면 + 0.5 m |

지형 위에서는 지면 대비 몸통 높이 0.31 m를 넘어짐 기준으로 사용한다. 관측의 높이는 원본과 같은 월드 z이다. 초기 지면 접촉 충격은 현재도 남아 있으며 아래에서 별도로 분석한다. 4,096개로 새로 학습할 경우 현재 코드는 5 m 격자를 수용하도록 지형을 320×320 m로 확장한다.

아래 학습 명령은 실제 사용한 task·체크포인트·학습량을 기록한 것이다. **현재 코드에서 다시 실행하면 복원된 설정으로 새 실험이 시작되므로 과거 실험의 완전한 재현 명령으로 보아서는 안 된다.** 당시 세부 설정은 각 실행 폴더의 `params/env.yaml`, `params/agent.yaml`에 남아 있다.

### 3.3 실험 A — 원본 보상 유지 + 환경 DR 파인튜닝

#### 보상함수

| 원본 항목 | 가중치 | 역할 |
|---|---:|---|
| progress | +1.0 | 목표까지의 거리 감소 |
| alive | +0.5 | 종료되지 않은 상태 유지 |
| upright | +0.1 | 몸통 수직 방향 유지, 투영값 기준 0.93 |
| move_to_target | +0.5 | 몸통 정면과 목표 방향의 정렬, 투영값 기준 0.8 |
| action_l2 | −0.005 | 큰 행동 명령 억제 |
| energy | −0.05 | 행동·관절 속도로 계산한 에너지 사용 대용 지표 |
| joint_pos_limits | −0.1 | 관절 한계 근처 사용 억제 |

RewardManager가 각 항목에 가중치와 제어 시간 간격을 곱해 스텝 보상을 만든다. `energy`는 실제 전력계로 측정한 에너지가 아니다.

#### 학습 명령어

```bash

  --num_envs 4096 --seed 42 --max_iterations 1000 \
  --resume \
  --load_run '2026-09-17_13-21-32_ant_baseline$' \
  --checkpoint 'model_999\.pt$' \
  --run_name baseline_ft_rough_blocks_original --headless
```

- 학습 누적 보상: 처음 100회 평균 **23.656 → 마지막 100회 평균 37.118**.

훈련 환경 안에서 보상과 에피소드 길이가 개선되어 적응이 진행된 것으로 해석한다. 이것만으로 미학습 지형 성능이 개선됐다고 결론 내리지는 않는다.

팀의 정성 관찰에서는 일부 다리로 노를 젓듯이 밀거나 몸통을 띄우며 전진하는 보행이 나타났다. **원본에 정면 방향 보상이 없는 것은 아니다.** `move_to_target`은 방향 투영값이 0.8보다 크면 보상이 일정해져, 그 구간 안의 추가 정렬을 강하게 구분하지 않는다. 몸통이 수평일 때는 약 36.9° 이내의 방향 오차가 이 구간에 해당한다.

원본에는 수직 속도와 몸통 좌우 속도를 직접 억제하는 항목이 없어, 전진 보상을 얻는 여러 보행 방식 중 비대칭 추진도 선택될 수 있다는 것이 **해석 가설**이다. 발 접촉 순서·위상이나 방향 오차를 통제한 별도 실험은 하지 않았으므로, 이 현상의 원인을 방향 보상 하나로 단정하지 않는다. 특히 시작 직후의 큰 튐은 아래 초기 접촉 진단으로 분리해야 한다.

### 3.4 실험 B — 추가 보상 + 환경 DR 파인튜닝

#### 추가한 보상

원본 7개 항목과 가중치를 유지하고, 아래 네 벌점을 추가한 Forward-Light 설정을 사용했다.

| 추가 항목 | 식과 가중치 | 의도 |
|---|---|---|
| 수직 속도 | `−0.5 × (v_z_world)²` | 과도한 상하 움직임 억제 |
| 롤·피치 각속도 | `−0.05 × (ω_x_body² + ω_y_body²)` | 몸통 회전 흔들림 억제 |
| 좌우 속도 | `−0.05 × (v_y_body)²` | 몸통 정면 기준 옆걸음 억제 |
| 방향 오차 | `−1.0 × (1 − cos(목표 방위각 − 몸통 yaw))` | 목표 방향으로의 연속적인 정렬 유도 |

이 항목들에도 RewardManager가 제어 시간 간격을 한 번 적용한다. 몸통의 +X가 정면이며, 특정 다리 하나가 정면인 것은 아니다. **평가 환경에서는 이 네 항목을 사용하지 않고 원본 7개 보상만으로 집계한다.**

#### 학습 명령어

### 3.6 초기 튐과 평가 해석의 한계

#### 초기 접촉 진단

시작 직후 크게 튀는 현상을 학습 정책의 점프 동작으로만 해석하지 않기 위해 모터 출력을 0으로 둔 대조 실험을 했다.

| 조건 | 첫 0.2초의 최대 상승 속도 · 100개 중 최댓값 | 해석 |
|---|---:|---|
| 원본 평지, 모터 출력 0 | 약 6.00 m/s | 원본 초기화에서도 튐이 발생 |
| 블록, 모터 출력 0 | 약 7.47 m/s | 정책 없이도 큰 튐이 발생 |
| 블록, 출력 0, 진단용 시작 높이 +0.10 m | 약 0.86 m/s | 초기 지면 접촉을 바꾸자 큰 튐이 크게 감소 |

몸통 아래 한 점을 기준으로 시작 높이를 정하면, 관절 각도와 주변 블록 높이에 따라 발·다리가 지면에 겹칠 수 있다. 이 겹침을 물리엔진이 해소하는 접촉 충격이 초기 튐의 주요 원인이라는 진단을 뒷받침한다. **+0.10 m는 원인 확인용 실험에만 사용했고, 본문 재평가나 실제 환경 설정에 적용하지 않았다.**

#### 해석 범위

1. **초기 접촉 충격:** 정책과 무관한 초기 실패가 보상과 생존 시간에 섞여 있다. 이번 표는 이 문제가 남은 조건에서의 결과이다.
2. **학습·평가 설정 차이:** 시작 배치, 마찰 결합 방식과 경계 처리가 바뀌었다. 미학습 지형 효과와 이 변경 효과를 완전히 분리하지 못했다.
3. **유한 지형:** 160×160 m 평가 지형 밖으로 나간 뒤 추락하는 경우가 있다. 빠르게 움직이는 정책이 경계에 더 자주 도달할 수 있어, 짧은 에피소드를 모두 균형 상실로 해석하면 안 된다.
4. **표본 범위:** 학습 seed 42 한 개와 평가 seed 24 한 개이다. 100개 환경은 100개의 독립 학습 모델이 아니며, 고정 지형을 공유한다. std는 모델별 학습 변동성이 아니다.
5. **학습량·보상 묶음:** 평지 추가 학습 대조군과 보상 항목별 제거 실험이 없어, DR 자체나 개별 벌점의 인과 효과를 분리할 수 없다.
6. **사전 평가 기록과 구분:** 배치 복원 전 블록 결과는 A **49.665639 ± 26.486469**, B **50.397475 ± 24.337423**이었다. 현재 표와 다른 조건이므로 섞어 쓰거나 변화량을 학습 효과로 해석하지 않는다.

## 4. 결론

### 4.1 확인한 내용

- 같은 평지 정책에서 시작한 두 파인튜닝 모두 **학습 환경 내 보상과 에피소드 길이가 증가**했다.
- 블록의 새 배치에서는 평균 보상이 소폭 높아졌으나, **미학습 물결에서는 평지 기준 모델보다 낮았다.** 다양한 환경을 학습하는 것만으로 모든 새로운 환경에 대한 강건성이 확보되지는 않았다.
- 추가 보상 모델은 원본 보상 파인튜닝보다 두 평가 환경에서 높은 평균 보상과 낮은 평균 절대 수직 속도를 보였다. 다만 보상 차이·단일 seed·초기 충격을 고려하면 **안정적인 보행이 완성됐다고 단정할 수 없다.**
- 노 젓듯 보이는 보행, 방향 정렬, 시작 직후 튐은 서로 다른 현상이다. **보상 설계와 초기 접촉 문제를 분리해서 분석하는 것이 중요하다.**

### 4.2 후속 검증

우선 발·다리가 지면에 관통하지 않는 시작 배치를 최소한으로 보정하고, 동일한 초기화·마찰·경계 조건에서 세 모델을 다시 비교해야 한다. 이후 평지에서만 1,000회 추가 학습한 대조군, 여러 학습 seed, 추가 벌점별 제거 실험을 통해 DR과 보상 설계의 효과를 분리한다. 방향 오차, 몸통 전방 속도, 발 접촉 순서도 측정하면 보행 모양에 대한 정성 관찰을 정량화할 수 있다.
