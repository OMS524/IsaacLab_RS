**평지 베이스 모델 · 원본 보상 DR 파인튜닝 · 추가 보상 DR 파인튜닝 비교**  
작성일: 2026년 10월 5일 · 최신 격자형 학습 결과 기준  
[외부 공유 보고서](https://ant-robustness-assignment1.dhalstjr5247.chatgpt.site)

> **핵심 결과:** 격자형 환경에서 평균 누적 보상은 평지 베이스 4.48 → 원본 보상 파인튜닝 12.69 → 추가 보상 파인튜닝 13.35로 증가했다. 미학습 물결에서는 51.20 / 53.55 / 50.38로, 추가 학습이 모든 새로운 지형에서 일관된 개선을 보장하지는 않았다.

## 1. 연구개요

### 연구 목적

평지에서 걷는 법을 학습한 Ant가 **지형과 마찰이 달라져도 전진과 자세 유지를 수행할 수 있는지** 확인한다. 평지에서는 일정한 발 접촉을 기대할 수 있지만, 요철에서는 접촉 높이와 지지 상태가 달라지고 마찰 변화로 미끄러짐이 발생할 수 있다.

이미 평지에서 1,000회 학습한 정책을 공통 출발점으로 삼아 두 가지 추가 학습을 비교했다. 하나는 원본 보상함수를 유지하고 환경만 다양화하는 방법이며, 다른 하나는 같은 환경에서 몸통 안정성과 정면 이동을 위한 벌점을 추가하는 방법이다.

로봇의 링크 길이·관절 개수·USD 하드웨어 구조와 정책 신경망은 변경하지 않았다. 이번 비교의 핵심은 **환경 도메인 랜덤화와 보상 설계**다.

### ‘새로운 환경’의 구분

| 평가 지형 | 학습과의 관계 | 해석 범위 |
|---|---|---|
| 사각 격자형 요철 | 파인튜닝에 포함된 종류·크기·높이이며, 평가 seed로 새 높이 배치를 생성 | 학습한 지형 분포 안에서의 적응과 새 배치 일반화 |
| 물결 지형 | 이번 파인튜닝에 포함하지 않은 생성 방식 | 학습하지 않은 지형 종류로의 일반화 |

격자형만 잘 걷는 것으로 과제 목표 전체를 달성했다고 판단하지 않는다. **미학습 지형 평가에는 물결 환경을 함께 사용**한다. 두 평가의 보상 크기가 다르므로 서로 다른 지형끼리 원점수를 직접 비교하기보다는, 같은 지형 안에서 세 모델을 비교한다.

## 2. 연구가설

### 비교 모델과 가설

| 모델 | 학습 방법 | 검증 역할 |
|---|---|---|
| **B0 · 평지 베이스** | `Isaac-Ant-v0`, 원본 보상으로 평지에서 1,000회 학습 | 추가 적응을 하지 않은 기준 정책 |
| **B1 · 원본 보상 + DR** | B0에서 원본 보상을 유지하고 혼합 지형·마찰 랜덤화로 1,000회 추가 학습 | 다양한 환경에 노출된 효과 확인 |
| **B2 · 추가 보상 + DR** | B0에서 B1과 같은 환경으로 1,000회 추가 학습, 안정성·방향 벌점 추가 | 보상 설계의 추가 효과 확인 |

- **H1:** 다양한 지형과 마찰 조건에서 파인튜닝하면 평지 베이스보다 환경 변화에 강건해질 것이다. B0와 B1을 격자형·물결에서 비교한다.
- **H2:** 상하·좌우 움직임, 롤·피치 회전, 방향 오차에 벌점을 주면 B1보다 안정적인 보행에 도움이 될 것이다. B1과 B2의 공통 평가 보상, 생존 시간, 동작 지표를 비교한다.

B1과 B2는 **같은 B0에서 각각 독립적으로 시작**한다. B1의 최종 모델을 B2에 이어 학습한 것이 아니다. 두 분기는 학습 seed, 환경 수, 학습량, 지형 설정, 마찰과 PPO 설정이 같고 보상만 다르다.

B0는 총 1,000회, B1/B2는 B0의 학습을 포함하면 총 2,000회 학습했다. 따라서 B0와의 차이를 **DR만의 인과 효과**로 단정할 수는 없다. 이를 분리하려면 평지에서만 1,000회 더 학습한 대조군이 필요하다.

### 3.2 공통 학습·평가 설계

#### 학습 설정

| 설정 | 값 |
|---|---|
| 학습 환경 수 / seed | 4,096 / 42 |
| B0 학습 / B1·B2 추가 학습 | 각각 1,000 PPO 업데이트 |
| 업데이트당 수집량 | 환경당 32스텝 = 전체 131,072 transition |
| 각 1,000회 실행의 수집량 | 131,072,000 transition |
| Actor / Critic | 각각 은닉층 400–200–100, ELU |
| 관측 / 행동 | 60차원 / 관절 effort 8차원 |
| PPO | learning rate 0.0005, adaptive, 5 epochs, 4 minibatches |
| 할인율 / GAE λ / PPO clip | 0.99 / 0.95 / 0.2 |
| 시뮬레이션 / 제어 주기 | 1/120초 / 1/60초 |
| 최대 에피소드 | 16초 = 960 제어 스텝 |
| 외란 | 없음 |

B1/B2는 `--resume`으로 B0의 정책·가치망과 optimizer 상태를 불러온다. `--max_iterations 1000`은 **추가 업데이트 1,000회**이며, 저장된 iteration 999부터 번호가 이어져 최종 파일이 `model_1998.pt`가 된다.

#### 도메인 랜덤화 설정 — 실제 최신 학습 YAML 기준

| 지형 | 생성 확률 | 설정 |
|---|---:|---|
| 평지 | 10% | `MeshPlaneTerrainCfg` |
| 불규칙 잔요철 | 30% | 높이 잡음 ±2.5 cm, 높이 간격 0.5 cm, 공간 샘플링 0.4 m |
| 사각 격자 | 40% | `MeshRandomGridTerrainCfg`, 칸 0.6×0.6 m, 높이 −6~+6 cm |
| 경사 | 10% | slope 파라미터 0.02~0.10 |
| 역경사 | 10% | 같은 경사 범위, 반대 형상 |

격자 높이는 연속 균등분포로 생성되며, 인접 칸의 높이 차이는 최대 약 12 cm다. `holes=False`, 중앙 플랫폼 폭 2 m를 사용한다. 경사 값은 도(degree)가 아니다.

학습 지형은 20×20 m 타일 16×16개, 총 320×320 m이며 지형 seed는 1701이다. 위 비율은 **타일 생성 확률**이다. 실제 타일 개수 비율이나 각 로봇이 경험한 시간 비율까지 정확히 같다는 뜻은 아니다. 지형을 매 스텝·매 에피소드 새로 생성하는 방식은 아니다.

마찰은 로봇별로 정지 마찰 0.5~1.25, 동적 마찰 0.4~1.0에서 배정하며 동적 마찰이 정지 마찰을 넘지 않도록 한다. 64개 후보 중 로봇마다 하나를 선택하고 리셋 간 유지한다. 지면 마찰은 1.0, 결합 방식은 `average`다.

#### 보상 설계

B0/B1은 원본 7개 보상을 사용한다.

| 항목 | 가중치 | 역할 |
|---|---:|---|
| progress | +1.0 | 목표까지의 거리 감소 |
| alive | +0.5 | 종료되지 않은 상태 유지 |
| upright | +0.1 | 몸통 수직 정렬, 투영값 기준 0.93 |
| move_to_target | +0.5 | 몸통 정면과 목표 방향 정렬, 투영값 기준 0.8 |
| action_l2 | −0.005 | 큰 행동 명령 억제 |
| energy | −0.05 | 행동·관절 속도 기반 에너지 사용 대용 지표 |
| joint_pos_limits | −0.1 | 관절 한계 근처 사용 억제 |

B2는 위 항목에 네 벌점을 더한다.

| 추가 항목 | 식·가중치 | 의도 |
|---|---|---|
| 수직 속도 | `−0.5 × v_z_world²` | 과도한 상하 움직임 억제 |
| 롤·피치 각속도 | `−0.05 × (ω_x_body² + ω_y_body²)` | 몸통 회전 흔들림 억제 |
| 좌우 속도 | `−0.05 × v_y_body²` | 옆으로 미는 움직임 억제 |
| 방향 오차 | `−1.0 × (1 − cos(목표 방위각 − 몸통 yaw))` | 목표 방향으로의 연속적 정렬 유도 |

RewardManager가 가중치와 제어 시간 간격을 곱해 스텝 보상을 계산한다. **평가에서는 B2도 추가 벌점 네 개를 제외한 원본 7개 보상만 사용**한다. 원본에도 방향 보상이 있으므로, 노 젓듯 보이는 보행의 원인을 ‘방향 보상이 없어서’라고 설명하지 않는다. 원본 방향 보상의 포화 구간, 다른 보상과의 균형, 접촉 상태가 함께 작용할 수 있다.

#### 평가 방법과 영상 조건

- 공통 CLI 조건: **`--seed 24 --num_envs 100`**, 외란 없음.
- 격자 평가: `Isaac-Ant-DR-Eval-Blocks-v0`, 지형 seed 2402, 0.6 m 격자·±6 cm 높이, 격자 지형 100%.
- 미학습 물결 평가: `Isaac-Ant-DR-Eval-v0`, 지형 seed 2401, 파장 구성이 다른 두 물결 종류, `amplitude_range=(0.03, 0.06)`.
- 각 로봇의 **첫 에피소드에 종료 스텝까지 포함**하고, 이후 자동 리셋된 에피소드는 집계에서 제외한다.
- mean과 std는 100개 누적 보상의 평균과 **모집단 표준편차**다. std는 평균의 신뢰구간이 아니다.
- ‘시간 제한까지 생존’은 실패 판정 없이 960스텝에 도달한 수이다. 목표 도착 성공률과는 다르다.

모든 수치는 보고서 작성 중 같은 현재 코드로 재평가했다. 계측에는 공식 `play_one_episode.py`와 같은 환경·모델 로딩·첫 에피소드 집계 절차를 사용하는 [보고서용 평가 스크립트](reports/assignment1/evaluate_grid_report.py)를 사용했다. 동작 지표를 읽고 보고서 전용 경로에 영상·JSON을 저장했으며, 태스크의 물리·보상·종료 조건과 체크포인트는 변경하지 않았다.

영상 세 개도 이번 **격자 평가와 동시에 새로 촬영**했다. 동일한 카메라로 0번 로봇을 따라간다. 약 16초 영상에는 0번 로봇의 조기 종료 후 자동 리셋 장면이 포함될 수 있지만, 표의 점수는 첫 에피소드만 반영한다. 영상 한 마리의 움직임이 100개 전체를 대표하는 것은 아니다.

TensorBoard 이미지는 실제 `events.out.tfevents.*`에서 추출한 그래프다. 얇은 선은 원래 로그, 굵은 선은 50회 이동평균이며, 표의 처음·마지막 100회 평균은 평활화 전 값으로 계산했다.

기준 모델 학습 설정에 해당하는 명령:

```bash
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/train.py \
  --task Isaac-Ant-v0 --num_envs 4096 --seed 42 \
  --max_iterations 1000 --run_name ant_baseline --headless
```

이 명령을 다시 실행하면 새로운 평지 학습이 시작된다. 본 보고서는 이미 존재하는 위 체크포인트를 평가했다.

### 3.4 B1 — 원본 보상 유지 + 환경 DR 파인튜닝

학습 실행: `2026-10-05_21-47-43_baseline_ft_rough_blocks_original`  
체크포인트: `logs/rsl_rl/ant/2026-10-05_21-47-43_baseline_ft_rough_blocks_original/model_1998.pt`

### 3.8 해석의 한계

1. **단일 학습 seed와 평가 seed:** 학습 seed 42, 평가 seed 24 한 쌍이다. 100개 병렬 환경은 독립 학습 100회가 아니고 지형 메시를 공유하므로, 현재 std를 학습 모델 간 변동성으로 해석하지 않는다.
2. **학습량 차이:** B1/B2는 B0보다 1,000회 더 학습했다. 같은 총 학습량의 평지 대조군이 없어 DR만의 효과를 완전히 분리하지 못했다.
3. **보상 묶음:** 네 벌점을 함께 추가했으므로 어느 항목이 효과를 냈는지 분리할 수 없다. 특정 보행 모양의 원인을 한 보상 항목으로 단정하지 않는다.
4. **초기 접촉:** 앞선 진단에서 출력 0에서도 초기 튐이 관찰됐다. 이번 평가도 기존 초기화 방식을 사용해 시작 직후 접촉 충격이 섞일 수 있다. 과거 ±2 cm 블록에서 측정한 튐 수치를 현재 ±6 cm 격자의 수치로 재사용하지 않았다.
5. **유한 평가 지형:** 평가 표면은 160×160 m다. 물결에서 지면 ray가 없는 상태로 종료된 수는 B0 31, B1 29, B2 25개였다. 지형 경계를 벗어나 지지면을 잃은 영향이 섞일 수 있으므로, 짧은 에피소드를 모두 보행 균형 상실로 해석하면 안 된다. 격자에서는 해당 수가 세 모델 모두 0이었다.
6. **보고서 범위:** 이 문서는 21:47·22:08의 새 격자형 파인튜닝 결과다. 이전 17:10·17:31 실행의 사각 블록/홈 결과와 합치지 않는다. 초기화·마찰 결합 방식은 이번 두 최신 학습과 평가에서 같은 현재 구현을 사용하지만, 지형 범위는 학습 320 m·평가 160 m로 다르다.

## 4. 결론

평지에서 학습한 Ant를 혼합 지형과 마찰 변화에 적응시키면 **학습한 격자 분포에서의 성능은 크게 개선**됐다. 평균 누적 보상은 B0 4.48에서 B1 12.69, B2 13.35로 높아졌고 시간 제한까지 생존한 수는 19 → 47 → 54/100으로 증가했다.

추가 보상은 격자에서 전진 성능을 유지하면서 몸통 움직임을 줄이는 데 도움이 되는 결과를 보였다. 다만 미학습 물결에서는 B1의 평균 보상이 가장 높았고 B2는 베이스보다 약간 낮았다. **안정성 벌점을 더하는 것과 모든 새로운 환경에서 더 잘 걷는 것은 같은 결과가 아니었다.**

따라서 이번 실험은 ‘여러 지형을 학습하면 무조건 강건해진다’보다, **학습 분포에 대한 적응과 새로운 지형 종류로의 일반화를 따로 검증해야 한다**는 점을 보여준다. 후속 실험에서는 동일 학습량의 평지 대조군, 여러 seed, 보상 항목별 제거 실험과 초기 접촉·지형 경계 영향을 통제한 평가가 필요하다.
